Privacy Policy

Effective date: September 16, 2026

This application is a personal project operated by a single individual for personal use only. It is not a commercial service and has no other users besides its owner.

What data is accessed

Using Google's Smart Device Management API (scope sdm.service), this application accesses Nest camera feed and thermostat status/control data belonging solely to the account holder's own Google account and own physical devices.

How the data is used

Data is used exclusively for local home automation within the account holder's own self-hosted Home Assistant instance — for example, displaying a camera feed or adjusting thermostat settings. It is never transmitted to, or stored on, any third-party or developer-operated server. No analytics, advertising, or data-sharing of any kind occurs.

Data storage and retention

OAuth tokens and device data are stored only locally on the account holder's own home server. Access can be revoked at any time via Google Account permissions, which immediately stops all data access.
